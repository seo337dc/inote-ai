# 글 찾기 검색 평가 세트

`scripts/eval_search.py`가 읽는 질문 파일을 둔다. 실행·출력 설명은 스크립트 docstring 참고. **개발 DB + 로컬 임베딩 서비스**로만 돌린다.

- `questions.example.json` — 형식 예시(정답 id는 자리표시자라 그대로 돌리면 "건너뜀"으로 나온다)
- `questions.json` — 실제 질문 (직접 만든다). 공개 글만 가리켜야 한다.
- `posts.local.md` — 질문을 쓸 때 참고하는 공개 글 id·제목 목록(`.gitignore`로 제외, 직접 뽑는다)

## 질문 쓰는 법
- 정답이 있는 질문 15~20개: **본문 문장을 그대로 베끼지 말고 바꿔 쓴다.** 글 앞부분 내용 반, 뒷부분(1,500자 이후) 내용 반이 되게 섞는다.
- 같은 주제의 글이 여러 편이면 `expect`에 모두 넣는다(하나라도 상위에 나오면 적중).
- 관련 글이 없어야 하는 질문 5~8개: `expect`를 빈 배열로. 글과 전혀 상관없는 질문과, 비슷한 분야지만 내 글에는 없는 질문을 섞는다.
